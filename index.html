1. Choose your features

Choose three morphological features and three syntactic features. The tool then pairs each morphological feature with the other two (three morphology–morphology pairs) and with each syntactic feature (nine morphology–syntax pairs).

Features from the WALS areas Nominal Syntax and Simple Clauses mix morphology and syntax, so they appear in both lists, marked “mixed”. If you are unsure which list such a feature belongs in, ask your instructor. Where WALS splits one topic into several features (for example 81A and 81B), the syntactic list offers only the first, “A”, feature.

Only features coded for at least 250 languages are offered. Many WALS features were coded only for a smaller sample of about 200 languages, and pairing two of those leaves too few languages to compare.
